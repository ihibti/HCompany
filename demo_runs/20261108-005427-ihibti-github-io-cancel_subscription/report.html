severity 3 sneaking step 11
“The system responds to the user's explicit cancellation request with 'All done! I've paused your account for 3 months' instead of canceling the subscription, which is a different outcome than what the user requested.”
The user explicitly requested to cancel their subscription immediately, but the system paused the account for 3 months instead, which is a different outcome that the user did not request. This is a clear case of the outcome being quietly different from what the user chose.
severity 2 asymmetric choice step 8
“The 'No thanks' option is a text link while 'Tell me more' is a button, making the decline option visually weaker than the acceptance option in both retention offers.”
The user's goal is to cancel, but the 'No thanks' option is styled as a less prominent text link compared to the 'Tell me more' button, making it harder to decline the retention offers.
severity 2 confirmshaming step 8
“The chatbot uses the phrase 'I really don't want to lose you' when presenting the second retention offer, which is emotionally manipulative language designed to make the user feel guilty for wanting to cancel.”
The wording 'I really don't want to lose you' is a guilt-inducing phrase that pressures the user to reconsider their cancellation decision.
severity 2 nagging step 8
“After the user declined the first offer with 'No thanks', the chatbot immediately presented a second retention offer: 'I really don't want to lose you — how about 3 months of Premium completely free? That's $47.97 of value, on us!'”
The system repeatedly presents retention offers after the user has already declined once, forcing the user to repeatedly say 'No thanks' to proceed with cancellation.
severity 2 obstruction step 3
“The modal requires re-entering the password with the text 'For your security, please re-enter your account details to continue to Customer Happiness.' and a 'Your Netflix password' field before the user can proceed toward cancellation.”
Requiring password re-entry adds an extra step that can delay or block the cancellation process.
severity 1 misdirection step 8
“The 'Sure, give me 3 months free' button is styled as a primary action button while 'No thanks' is a text link, drawing attention to the retention offer rather than the cancellation path.”
The visual hierarchy prioritizes the retention offer over the user's actual goal of cancellation, making it more likely the user will accidentally accept the offer.
