The 'No thanks' button is visually weaker than the 'Tell me more' button, which is the primary option for the discount offer. This makes it harder for the user to decline the offer and continue with their cancellation, as the 'No thanks' option is less prominent and easier to overlook.

Requiring password re-entry is an extra step that adds friction to the cancellation process. While it may be a security measure, it creates an unnecessary barrier for users trying to cancel their subscription, which is a common dark pattern used to make cancellation more difficult.
