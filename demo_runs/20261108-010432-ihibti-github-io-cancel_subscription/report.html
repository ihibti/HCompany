severity 2 asymmetric choice step 6
“The 'Claim my free month' button is a prominent red button, while the 'Continue to cancel instead' option is a plain text link with no button styling, making the cancellation path visually weaker and harder to find.”
The user's goal is to cancel their subscription, but the interface makes the cancellation option significantly less prominent than the retention offer. The red 'Claim my free month' button draws attention and is the primary call-to-action, while the actual cancellation path is a small, unstyled text link that is easy to miss or overlook.
severity 2 hidden option step 2
“The 'Your plan' section shows subscription details but the only visible action is 'Help Center' — no direct 'Cancel' or 'Account' option is present on this main page, requiring the user to navigate through the profile avatar or help center to find cancellation options.”
The cancellation option is not directly accessible from the main account view. The user must navigate through the profile avatar (DU button) or the Help Center to find account management options, which adds unnecessary steps to the cancellation process.
severity 2 misdirection step 6
“The modal displays 'Wait! Here's a FREE month 🎁' with a prominent red 'Claim my free month' button as the primary action, while the actual cancellation option 'Continue to cancel instead' is a small text link below it.”
The design uses a free month offer as a distraction from the user's cancellation goal. The modal's title and primary button are designed to capture attention and encourage the user to accept the retention offer rather than proceed with cancellation, which is the user's stated goal.
severity 2 obstruction step 3
“The 'Your plan' section only provides a 'Help Center' button as the sole action for managing the subscription, forcing the user to navigate through an additional layer (Help Center) rather than offering a direct 'Cancel' or 'Manage Subscription' option on the main account page.”
The user's goal is to cancel a paid subscription, but the interface only offers a 'Help Center' button as the next step. This creates an unnecessary extra step that adds friction to the cancellation process, as the user must navigate through the Help Center to find cancellation options rather than having a direct path from the account overview page.
