Dark patterns detected

severity 3 obstruction step 5
“The page forces the user to engage in a chat with 'Nina from Customer Happiness' to cancel their subscription, adding an unnecessary step instead of providing a direct cancellation option. The 'Send' button is the only actionable element, requiring the user to type a message before any cancellation process can begin.”
This chat interface creates an extra layer of interaction that the user did not request, making the cancellation process more difficult than it should be. The user must first initiate a conversation before they can even start the cancellation process, which is a clear obstruction to their goal.
severity 3 sneaking step 10
“The user explicitly requested 'Cancel my subscription now. I do not want any offers.' but the system responded with 'All done! I've paused your account for 3 months' instead of canceling the subscription as requested.”
The user clearly stated they wanted to cancel their subscription, but the system presented a pause as if it were the cancellation. This is a classic sneaking pattern where the outcome is quietly different from what the user chose - the user asked for cancellation but received a pause instead, which is a different action that doesn't fulfill their goal of ending the subscription.
severity 2 nagging step 8
“After the user clicked 'No thanks' to the first 50% off offer, the chatbot immediately presented a second retention offer: 'I really don't want to lose you — how about 3 months of Premium completely free? That's $47.97 of value, on us!' with options 'Sure, give me 3 months free', 'Tell me more', and 'No thanks'.”
The system is persisting with retention offers after the user has already explicitly declined the first offer, which is a classic example of nagging. This adds friction to the cancellation process by repeatedly pushing the user toward retention instead of allowing them to proceed with their stated goal of canceling.
