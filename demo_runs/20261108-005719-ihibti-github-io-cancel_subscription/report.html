severity 2 asymmetric choice step 8
“The 'Claim my free month' button is a large, prominent red button, while the 'Continue to cancel instead' option is a small, unobtrusive text link below it. This visual hierarchy makes the cancellation option significantly harder to find and select compared to the retention offer.”
The design makes the business-preferred action (claiming the free month) visually dominant while the user's intended action (cancellation) is de-emphasized, creating an imbalance that works against the user's goal.
severity 2 confirmshaming step 7
“Looking to make changes to your membership? If you wish to end your membership, our retention team would love to help — click here to see how.”
The phrase 'our retention team would love to help' uses guilt-tripping language to discourage cancellation by framing the company's desire to retain the user as a positive action, making the user feel bad for wanting to cancel.
severity 2 obstruction step 2
“The 'Your plan' section displays subscription details but only provides a 'Help Center' button and a text link to 'Visit our Help Center' for questions, with no direct 'Cancel' or 'Manage' button visible on the page. This forces the user to navigate through additional steps to find the cancellation option.”
The absence of a direct cancellation option on the main account page forces the user to seek help through the Help Center, adding unnecessary steps to the cancellation process. This is a clear obstruction that hinders the user's goal of canceling their subscription.
