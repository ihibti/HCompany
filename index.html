The Netflux Gauntlet

Five fictional subscription flows of increasing hostility. Each level is a real web app an agent must fight through to cancel. Pick a level to play it by hand, or point an Escape Hatch agent at levelN/.

What is Escape Hatch?

Escape Hatch is a computer-use agent that tries to leave websites for you — refusing cookies, cancelling subscriptions — and measures every dark pattern standing in the way, with screenshot evidence and a friction grade. This gauntlet is its benchmark: five fictional Netflux flows where an agent must find the exit while we score effort and pattern detection against ground truth (levels.json).

Netflux is a fictional demo service — all flows, prices and characters are invented for this benchmark.
